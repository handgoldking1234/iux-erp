# IUX ERP 시안

Claude Design으로 만든 ERP·그룹웨어(GW) 대시보드 시안입니다.

## 화면

- `GW Dashboard.dc.html` — 그룹웨어 대시보드 (전자결재, 게시판, 출퇴근, 일정)
- `ERP Dashboard.dc.html` — ERP 대시보드 (수주·매출·수금 현황, 월별 추이, 사업유형별 비중)
- `index.html` — GW 대시보드로 이동하는 시작 페이지

두 화면은 상단 메뉴의 ERP / GW 탭으로 서로 오갈 수 있습니다.

## 폴더

- `assets/` — 로고
- `uploads/` — 시안 작업 때 참고한 이미지
- `support.js` — Claude Design 화면 런타임

## 보기

`index.html`을 브라우저로 열면 됩니다. 폰트(Pretendard)는 CDN에서 불러옵니다.
